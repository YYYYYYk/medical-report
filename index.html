� 逐项解读 · 专业建议

1｜血小板 PLT（98 → 93 → 79，参考 125-350）　⚠️ 需重点关注 解读：呈进行性下降，且10.12为历次最低。多见于肝硬化门静脉高压引起的脾功能亢进（脾脏对血小板破坏增多），也需排除骨髓造血功能受抑。血小板持续走低会带来出血风险，若降至 50 以下风险明显升高。 建议：定期（每1-3个月）复查血常规；注意有无牙龈出血、皮肤瘀斑、黑便等；避免磕碰；必要时消化科/血液科评估，考虑胃镜下套扎食管静脉曲张、脾动脉栓塞等措施；血小板过低或发生出血时立即就医。 2｜血红蛋白 HGB（168 → 154 → 151，正常 130-175）　✅ 仍在正常区间 解读：值较高位缓慢回落，仍处于正常范围。肝硬化患者可能因门脉高压致消化道隐性失血、或脾功亢进的轻度消耗。 建议：随访血常规；如继续下降，可查血清铁蛋白和粪便隐血，排查隐性出血。 3｜ALT（50 → 20 → 27）与 AST（38 → 23 → 26）　✅ 炎症明显减轻 解读：转氨酶由3月的临界偏高/偏高，回落并稳定在正常范围，提示肝细胞炎症较前明显减轻，抗病毒/保肝治疗有效。 建议：维持抗病毒治疗（如适用），规律复查肝功能；避免擅自停药。 4｜总胆红素 TBIL（21.6 → 16.0 → 15.36）与直接胆红素 DBIL（7.0 → 4.6 → 4.39）　✅ 黄疸好转 解读：3月胆红素偏高，后持续下降并恢复正常，提示胆汁分泌与排泄功能改善。 建议：联合转氨酶、白蛋白、肝纤四项综合评估肝脏储备，定期复查。 5｜肌酐 CREA（63 → 69 → 71，正常 45-104）　🏷 正常范围但呈上升趋势 解读：虽仍在正常范围，但三次呈上升趋势。可能与年龄、用药或肾血流量变化相关。肝硬化患者需警惕肝肾综合征。 建议：复查肾功能（血肌酐、尿素氮、尿常规）；慎用肾毒性药物；维持水化。 6｜其余项目（WBC 4.99→4.39→4.61、GGT、ALP、LDH、TP、ALB、URIC） 均处于正常范围，波动幅度小，属正常生理波动。白蛋白稳定在正常值是肝脏合成功能良好的标志，继续保持均衡营养与充足蛋白摄入即可。
